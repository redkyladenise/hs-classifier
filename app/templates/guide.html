How to Use This Tool

Learn how the hierarchy works, how to write strong descriptions, and how to interpret your HS code classification results.

Understanding the Hierarchy

The Harmonized System (HS) and ASEAN Harmonized Tariff Nomenclature (AHTN) use a cascading numbering system. Here is what each level means.

84
2-Digit Chapter

The top-level broad category of the customs code (e.g., Machinery and Mechanical Appliances).

8471
4-Digit Heading

The second level categorization grouping specific types of items within the chapter (e.g., Automatic data processing machines).

8471.30
6-Digit HS Subheading

The internationally recognized level shared by all World Customs Organization (WCO) countries (e.g., Portable computers under 10kg).

8471.30.20
8-Digit AHTN Subheading

The highly specific tariff line adopted strictly within ASEAN and the Philippines, determining the exact duty rate.

Writing a Good Description

The model relies on matching physical and functional keywords to historical customs data. A single word like "parts" will return low confidence across multiple chapters. For the best accuracy, you may include these four elements:

  1. Identity: What exactly is the item? (e.g., "dining chair")
  2. Material: What is it made of? (e.g., "stainless steel")
  3. Function: What does it do? (e.g., "for water supply")
  4. Specs: Size, capacity, or voltage (e.g., "2 inches")

Example

Vague Description
"metal pipe" (Lacks specific material, dimensions, and intended use)
Strong Description
"Seamless stainless steel pipe, 2 inches diameter, for water supply"

Interpreting the Results

The classifier displays several indicators to guide you make an informed decision. Here is what each element means.

Confidence Badges

Indicates how statistically sure the system is (High, Medium, Low). You must always manually review results labeled as Low.

Deepest Confident Level

A banner that tells you exactly how far down the hierarchy the model trusts its prediction before requiring your human judgment.

Alternative Candidates

The system's top 5 predictions. If the primary prediction looks incorrect, check these alternatives.

Similar Past Declarations

Examples of how similar descriptions were classified in historical data. Use this as a reference, not a legal guarantee.

Vagueness Flag

A warning triggered if your description lacks detail (e.g., just "parts"). Add material or function to improve the classification.

Out-of-Scope Message

Appears if your item falls outside the supported chapters. In this case, you may use outside resources directly.
