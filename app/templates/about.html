About the HS Classifier

An assistant for customs brokers and small importers that suggests AHTN codes from a product description.

What it does

  • ✓ Suggests codes at 2, 4, 6, and 8 digits
  • ✓ Shows confidence levels for each suggestion
  • ✓ Displays similar past declarations as evidence

What it does not do

  • ✗ Provide an official classification
  • ✗ Replace a formal advance ruling
  • ✗ Calculate duty rates

How it works

1. Clean

The text is cleaned up.

2. Predict

Models walk down the code hierarchy.

3. Confidence

A confidence level is attached.

4. Evidence

Similar past declarations are shown.

Scope

This tool currently supports five chapters of the AHTN 2022 tariff schedule. These chapters cover about half of the in-scope trade (13,509,223 transactions). If you enter a description outside these chapters, the tool will show an out-of-scope message.

Data Source

The system is trained on Bureau of Customs declarations for 2023–2025, compiled by BetterGov.ph, using the AHTN 2022 schedule.

Data accessed: October 2026.

Important Limitations

  • Declared codes are not verified. About one in five transactions (20.39%) belongs to a description declared under more than one code.
  • Label errors may exist even where descriptions agree (low-confidence audit estimate: 36.51%).
  • Tariff-line suggestions are mostly low confidence and need verification.
  • Similar past declarations are unverified and can repeat filing mistakes.
  • Accuracy falls on later years and new products. The next HS edition takes effect on 1 January 2028.

Responsible Use & Privacy

Always verify codes with the Tariff Finder or an advance ruling. No product descriptions are stored by this tool.
