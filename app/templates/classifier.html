Exported Data Dictionary

This CSV contains 21 columns of diagnostic data for each classification result. The following sections describe each column and its purpose.

1. Input & Processing
  • row_number: Original row position in the uploaded CSV file.
  • description: Original item description provided in the input file.
  • status: Processing outcome (success, out_of_scope, or error).
  • scope: Indicates whether the item falls within the system's supported chapters.
2. Classification Results & Confidence
  • chapter: Predicted 2-digit HS chapter code and its confidence score.
  • heading: Predicted 4-digit HS heading code and its confidence score.
  • subheading: Predicted 6-digit HS subheading code and its confidence score.
  • line: Predicted 8-digit AHTN tariff line code and its confidence score.
  • deepest_confident_level: Deepest hierarchical level at which the model meets the required confidence threshold.
3. Verification & Alternative Predictions
  • verification_required: Indicates whether the classification requires human review.
  • line_candidates: Alternative tariff line codes identified by the model.
4. Retrieval Diagnostics
  • vagueness_flag: Indicates whether the input description contains overly generic terms.
  • retrieval_top_code_L4: Closest historical match at the 4-digit heading level.
  • retrieval_split_notice: Indicates whether similar historical declarations have conflicting classifications.
5. System Metadata
  • model_version: Version of the classification model used for the prediction.
  • run_date: Date and timestamp when the batch was processed.
